# ぎょふ海苔の麻雀ナビ

試用版のアプリです。スマホのブラウザで開いて、手牌を入力するとおすすめの一手と理由が出ます。

## 使い方

- `index.html` をブラウザで開く
- 牌をタップして手牌を入力
- 5枚以上になるとおすすめ候補が表示される
- 画面の下の「カメラ補助」を使うと、写真から牌候補の確認ができる

## 公開方法

GitHub Pages で公開する場合:

1. GitHub のリポジトリにこのファイル群を push
2. Settings → Pages
3. Deploy from a branch を選択
4. `main` ブランチ、`/(root)` を選択
5. 保存
6. URL を LINE で友人に共有

## 補足

この版は試作です。まだ正式な麻雀の役判定や点数計算までは入っていません。初心者向けに「今の一手と理由」を短く伝えることを優先しています。
